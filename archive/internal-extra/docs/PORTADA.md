# Oráculo SOC Credential Dictionary Index

## Purpose

This section stores credential dictionaries derived from honeypot observations.

The goal is defensive reuse:

- password dictionary generation
- user/password pair analysis
- repeated credential tracking
- brute-force pattern support
- local SOC detection support

## Separation

Credential dictionaries are not payloads.

Credential dictionaries are not IP intelligence.

Credential dictionaries live in this private section only.
